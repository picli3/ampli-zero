# ampli-zero

Proyecto de amplificador de audio desarrollado en KiCad, orientado a una etapa de salida discreta y a la exploración práctica de una topología de amplificación analógica compacta.

## Propósito del proyecto
Este diseño parece estar pensado como una base para construir o experimentar con un amplificador de audio discreto, integrando los elementos necesarios de polarización, acoplo y etapa de potencia en una sola PCB.

## Qué incluye
- esquemático del amplificador
- diseño PCB en KiCad
- base reutilizable para análisis, pruebas y fabricación
